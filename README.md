# منصة يوسف علاء التعليمية

نسخة Static متعددة الصفحات جاهزة للنشر على Cloudflare Pages، مع Firebase للمصادقة وFirestore وCloudinary للوسائط.

## الموجود

- تسجيل الطلاب ببيانات الهوية والصف والمدرسة وأرقام الطالب وولي الأمر، مع حالة قيد المراجعة.
- تقديم المدرسين بحالة قيد المراجعة قبل تفعيل صلاحيات المدرس.
- أدوار: طالب، مدرس، مساعد مدرس، مدير، مالك.
- إدارة الكورسات والدروس والامتحانات وبنك الأسئلة مع مسار مراجعة قبل النشر.
- سلة شراء متعددة الكورسات ودفع يدوي وإرفاق إيصال.
- أكواد تفعيل أحادية الاستخدام للدرس والكورس والاشتراك والخصم.
- محافظ مدرسين وعمولات وطلبات سحب وسجل معاملات.
- فيديوهات Cloudinary مع استكمال الموضع، سرعات التشغيل، فصول، تتبع مشاهدة وعلامة مائية.
- امتحانات متعددة الأنواع، حتى 3 محاولات، عشوائية الأسئلة والاختيارات، وتصحيح يدوي للمقالي والملفات.
- ملاحظات مرتبطة بوقت الدرس، إشعارات، دعم، ولوحة متفوقين.
- قواعد Firestore مقفلة افتراضيًا مع صلاحيات منفصلة للطالب والمدرس والإدارة.
- لا توجد حسابات طلاب أو مدرسين أو كورسات أو إحصائيات وهمية مزروعة في المشروع.

## Firebase

- `.firebaserc` يحدد مشروع Firebase: `youssef-alaa-academy`.
- `firebase.json` يربط Firestore بملف `firestore.rules`.
- `firestore.rules` هي مصدر صلاحيات Firestore في المشروع.
- إعدادات Firebase Web موجودة في `config.js`.
- لا تضع API Secret أو Service Account داخل ملفات الموقع.

## Cloudinary

رفع الملفات يتم من المتصفح باستخدام Cloudinary Upload Preset غير موقّع. لا تضع API Secret في الواجهة. إعدادات Cloudinary الحالية موجودة في `config.js`.

## Cloudflare Pages

المشروع Static ولا يحتاج Build Command. ارفع محتويات المستودع كما هي، وسيعمل `index.html` كنقطة البداية.

## بيانات التشغيل

المشروع لا ينشئ مدرسين أو طلابًا أو كورسات تلقائيًا. بعد تجهيز Firebase، أنشئ حساب المالك يدويًا في Authentication ثم أنشئ مستند `users/{UID}` بالقيم:

- `role: "owner"`
- `status: "active"`
- `reviewState: "approved"`

بعد ذلك تتم إضافة المدرسين والطلاب من خلال المنصة.

## ملاحظات مهمة

تسجيل الدخول الحالي بالبريد الإلكتروني وكلمة المرور. SMS OTP ليس جزءًا من إعدادات النسخة المجانية الحالية. حماية منع تصوير الشاشة من المتصفح ليست مطلقة. تصحيح الإجابات الموضوعية يتم في العميل، لذلك الامتحانات شديدة الحساسية تحتاج لاحقًا طبقة خادمية إضافية.
